The Minotari base node is the backbone of the Tari network. It validates every block and transaction, maintains a full copy of the blockchain, participates in peer-to-peer gossip, and exposes a gRPC API that wallets, miners, and exchange backends use to interact with the chain. Running your own node gives you a trustless, private connection to the Tari network without relying on any third party.

## What the base node does

When you run `minotari_node`, it connects to the Tari peer-to-peer network, downloads and verifies all blocks from genesis, and keeps your local copy of the chain up to date. Once synced, the node:

- **Validates and stores the blockchain** — every block and transaction is checked against the Tari consensus rules before being written to the local database.
- **Serves the P2P network** — your node relays transactions and blocks to peers, strengthening the network's resilience and decentralization.
- **Exposes a gRPC API** — the base node binds a gRPC server to `127.0.0.1:18142` by default. Wallets, miners, and exchange integrations use this API to submit transactions, query balances, monitor the chain tip, and more.

## Published binaries

Each Tari release ships five binaries. You can download them from [tari.com/downloads](https://tari.com/downloads) or build them from source.

| Binary | Role |
|---|---|
| `minotari_node` | Full base node — validates and stores the blockchain, serves the P2P network and gRPC API on port 18142. |
| `minotari_console_wallet` | Terminal wallet for sending, receiving, and managing XTM. Exposes a gRPC API on port 18143 when enabled. |
| `minotari_miner` | Standalone SHA-3 miner. Connects to a base node over gRPC to mine blocks. |
| `minotari_merge_mining_proxy` | Lets you merge-mine Tari alongside Monero via XMRig. Acts as a proxy between XMRig and the Tari network. |
| `minotari_offline_signer` | Signs one-sided transactions on an air-gapped machine, keeping private keys completely offline. |

<Note>
  All five binaries are included in every release package from [tari.com/downloads](https://tari.com/downloads) and in the [GitHub releases](https://github.com/tari-project/tari/releases). The repository also contains additional tools (MCP servers, peer-sync diagnostics, utilities) that are built from source but not shipped in release packages.
</Note>

## Available networks

Tari operates three networks. You select a network at startup with the `--network` flag or by setting `network` in `config.toml`.

| Network | Flag value | Purpose |
|---|---|---|
| Mainnet | `mainnet` | Production network with real XTM value. Use this for all exchange integrations and live wallets. |
| Testnet (Esmeralda) | `esme` | Development and testing network. Tokens have no real-world value. Free tokens are available from the faucet. |
| Nextnet | `nextnet` | Pre-release network for testing features before they are promoted to Mainnet. |

See the [Networks](/node/networks) page for a full comparison and instructions on switching between networks.
