Tari is an open-source, privacy-first blockchain built for both everyday users and developers. Layer 1 (Minotari) is secured by proof-of-work mining and rewards you with XTM tokens. Layer 2 (the Ootle) is a high-performance smart-contract network where you can build and deploy decentralized applications using Rust-based templates.

## Quick Start Paths

<Steps>
  <Step title="Mine XTM with Tari Universe">
    [Download Tari Universe](https://tari.com/downloads) for Mac or Windows, install it, and start mining immediately. No cryptocurrency knowledge required.
  </Step>
  <Step title="Run a Base Node">
    Download `minotari_node` from [tari.com/downloads](https://tari.com/downloads), run it, and sync to the Tari network. See the [installation guide](/node/installation) for full instructions.
  </Step>
  <Step title="Integrate XTM into Your Exchange">
    Follow the [Exchange Integration guide](/exchange/overview) to set up a Minotari node, configure wallets, and use the gRPC API to monitor deposits and process withdrawals.
  </Step>
  <Step title="Build on the Ootle">
    Install Rust, run `cargo install tari-ootle-cli`, and follow the [Getting Started guide](/ootle/getting-started) to write and publish your first smart contract template.
  </Step>
</Steps>
